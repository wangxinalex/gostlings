# Sort：内置排序与自定义顺序

按 1–3 顺序完成。先会用 `sort` 的内置排序，再练习自定义比较，最后使用
Go 1.21+ 的 `slices.SortFunc`。

| 题目 | 重点 | 练习目标 |
| --- | --- | --- |
| sort1 | `sort.Strings` / `sort.Ints` | 内置切片排序 |
| sort2 | `sort.Slice` | 自定义比较函数 |
| sort3 | `slices.SortFunc` + `cmp.Compare` | 比较式排序 |

参考：[sort package](https://pkg.go.dev/sort)、[slices package](https://pkg.go.dev/slices)
