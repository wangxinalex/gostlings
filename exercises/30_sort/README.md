# Sort: built-in sorting and custom order

Work through 1–3 in order. First use the `sort` package's built-in sorts, then
practice custom comparators, and finally use Go 1.21+'s `slices.SortFunc`.

| Exercise | Focus | Goal |
| --- | --- | --- |
| sort1 | `sort.Strings` / `sort.Ints` | Built-in slice sorting |
| sort2 | `sort.Slice` | Custom comparator |
| sort3 | `slices.SortFunc` + `cmp.Compare` | Comparison-based sorting |

Reference: [sort package](https://pkg.go.dev/sort),
[slices package](https://pkg.go.dev/slices)
