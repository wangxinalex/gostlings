# Fmt：格式化动词与输出

按 1–3 顺序完成。这里练习 `fmt` 的格式化动词、宽度精度和向任意 `io.Writer`
写格式化输出；字符串的拼接与清洗见 `27_strings`。

| 题目 | 重点 | 练习目标 |
| --- | --- | --- |
| fmt1 | `%v` / `%+v` / `%#v` | 打印结构体的三种层次 |
| fmt2 | `%-10s` / `%.2f` | 宽度对齐与小数精度 |
| fmt3 | `fmt.Fprintf` | 向 `io.Writer` 写格式化输出 |

参考：[fmt package](https://pkg.go.dev/fmt)
